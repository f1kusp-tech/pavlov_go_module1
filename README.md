# Игра «Угадай число» на Go

Консольная угадайка чисел. Написана на чистом Go без внешних зависимостей. Код разбит на функции, глобальных переменных нет, потоки ввода защищены от падений и зависаний.

## Фичи
* **Валидация ввода:** Парсит ошибки `strconv.Atoi`. Если ввести буквы или пустую строку, игра не падает, а просит повторить ввод. Попытка при этом не сгорает.
* **Подсказки по расстоянию:** Функция `giveHint` берет разницу по модулю и выводит:
  * Разница ≤ 5 — 🔥 «горячо»
  * Разница ≤ 15 — 🙂 «тепло»
  * Больше 15 — ❄️ «холодно»
* **Вывод истории раунда:** На каждом шаге показывает слайс со всеми предыдущими ходами текущей сессии.
* **Три уровня сложности:**
  * Easy: от 1 до 50, 15 попыток
  * Medium: от 1 до 100, 10 попыток
  * Hard: от 1 до 200, 5 попыток
* **Сыграть еще раз:** Основной цикл крутится в меню. После окончания игры можно сразу стартовать новый раунд без перезапуска бинарника.
* **Логирование в JSON:** Все результаты пишутся в `results.json` (дата, статус победы/поражения, сколько попыток ушло). История автоматически подгружается при старте приложения.
* **Цветной терминал:** Вывод раскрашен через нативные ANSI escape-коды (`\x1b`). Работает «из коробки» в VS Code и современных терминалах. Победа — зелёный, фейлы — красный, попытки — жёлтый.

## Как запустить

```bash
go run main.go
```
